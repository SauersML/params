MAC NATIVE-NEURON READER FIT: COMPLETED, NO NUMERICAL ADVANTAGE

Question: can the same 35B reader learn intervention-effect predictions from 24 measured examples, with exact original prompts? This is an exposed-data fit diagnostic, not a fresh scientific evaluation or explanation benchmark.

Compute: Mac M5Pro GPU, no paid API or rental calls. 80 updates completed; 151,552 LoRA parameters on final full-attention layer 39 q/v/o, rank 8. Base model bytes unchanged before/after. Peak training MLX memory 25.728 GB. Evaluation: 32 first greedy answers, max 512 tokens, no retries; 123.971 s guarded wall time, 21.097 GB peak physical footprint. 32 GiB physical limit was respected. MATS had no immediate GPU admission.

Results: mean absolute error in bits, lower is better.

All 32 fine-tuned answers satisfy the original strict schema, normal stop, numeric finiteness and reason-length constraints. Original reader had 8 format failures. Fine-tuning improved format and numerical error relative to original, including the format-relaxed comparison, but did not beat the zero-effect baseline on 8 DEV or same-data ridge on TRAIN or DEV. Eight development cases and their labels were already exposed before this experiment. These are descriptive results, not unseen generalization estimates.

The ridge baseline was fitted on exactly the same 24 examples, with alpha selected by TRAIN-only leave-one-out validation and scaling refit within each fold. Its 32 predictions were frozen before adapter evaluation. Old ridge results remain separately reported; they are not the same-supervision comparison.

Protocol: fixed 80 checkpoint, no best-development checkpoint choice. Initial real-model evaluation/training-mode loss parity was exactly zero error. Completion-only loss excludes prompts and padding and includes EOS. The installed trainer validates before numbered steps 1/40/80: logged losses 3.487/0.367/0.353 correspond to 0/39/79 updates, not 0/40/80. Final generation uses 80 updates. Low token loss does not establish accurate intervention estimates, since most supervised tokens encode the fixed response format and neutral reason.

Scientific limit: the original 8B target's 16 neurons and conditional digit contrast are unchanged. No new target forwards were needed. This run trains a reader, not the target. Native-neuron evidence dependence was not established; absent/mismatched posttraining controls were not run because the trained reader already failed the basic same-data numerical comparator. No neuron names or English mechanisms were inferred or verified here.

Decision: do not scale this last-layer numerical training recipe on the evidence obtained. Retain the fast, hash-bound native-activation ridge as a development baseline/tool. The next useful oracle experiment must test answers on new mechanism questions against equal-budget tools and prompting, with true/absent/mismatched evidence controls; a lower completion loss alone is not a gate to more training. This does not establish the overall oracle goal.
